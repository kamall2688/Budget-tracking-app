# 💰 Ledger — Local-First Budget Tracker

A lightweight budget tracker that runs entirely in your browser. No accounts, no servers, and no setup required. All data is stored locally on your device using localStorage.

# ✨ Features

- Add income and expense entries
- Track balance automatically
- Filter transactions by type
- View spending by category
- Export data to CSV
- Works offline after loading
- Data persists between visits

# 🛠️ Tech Stack

- HTML5
- LocalStorage API

No frameworks, build tools, or external dependencies.


# 🔒 Privacy

Ledger is completely local-first:

- No sign-up required
- No tracking or analytics
- No cloud storage
- No data sent to any server

Your financial data stays on your device.

# ⚠️ Notes

- Data does not sync between devices.
- Clearing browser data will erase saved entries.
- Export CSV backups regularly if the data is important.
